# 🎸 ギターコード サポート

カポ相対・ディグリー表記で考える、ギター練習＆作曲支援Webアプリ。

ブラウザだけで動きます。ビルド不要・依存ライブラリゼロ・外部通信なし。音はすべて Web Audio API による合成音です。

## 中核コンセプト

このアプリは3つの原則で貫かれています。

1. **カポ相対でコードを同一視する** — カポからの相対位置で同じ押さえ方なら、カポが何フレットにあっても同じコードとして扱います
2. **表記はディグリー（I, IIm, V7…）** — 絶対音名をコード名として出しません。キーが変わっても同じ譜面がそのまま通用します
3. **音は絶対音で鳴らす** — 発音時だけ `開放弦 + チューニング + カポ + フレット` で実音を計算します

## 機能

### 練習

- **フレットボード表示** — SVGでネック全体を描画。カポ・バレー・開放弦・ミュートを表示、弦をクリックで単音試聴
- **コードデータベース** — 25クオリティ × 12ルートで500以上のボイシング。CAGEDシステムのフォームを網羅
- **チューニング** — レギュラー / 半音下げ / 全音下げ / 1音半下げ
- **カポ** — 0〜8フレット。実音キーを常時表示
- **エフェクト** — オーバードライブ / コーラス / ディレイ / リバーブ（プリセット4種付き）
- **ソロ練習** — 指板にスケールを表示。バッキング再生に追従して「今のコードの構成音」がリアルタイムでハイライト

### 入力・解析

- **コード登録** — フレットボードをクリックして押さえ方を入力すると、コード名を自動解析。既知のコード表と照合し、該当がなければ音程構造から名前を組み立てるので **必ず何かしら判定します**（`m7(9,♭13)` のような表記も生成）
- **コード進行** — ディグリーを並べて再生。コードごとの拍数（1/2/4/8拍）、BPM、ループ、ストロークパターン（シンプル / 4つ打ち / 8ビート / アルペジオ / ピアノロール）

### 作曲

- **メロディー・ピアノロール** — 行がキーのスケール音なので外れた音になりません。置いた音がコードトーンなら緑、テンションならオレンジに色分け。音色は声（フォルマント合成）とギターを切替可能
- **バッキング・ピアノロール** — 縦6行＝ギターの6弦。そのコードで鳴る弦だけ選択可能で、音の高さは押さえ方が自動で決めます。縦ドラッグで和音を一括入力
- **コード境界のドラッグ** — 8分音符単位でコードチェンジの位置を前後に動かせます（アンティシペーション＝食い気味のリズムが作れる）

### フレーズ→TAB（自動運指）

- **ピアノロールでフレーズ入力** — 行は半音単位。白鍵＝キーのメジャースケールで、キーを変えると白鍵の位置もずれる（Gキーなら「ド」の段が「ソ」）。同時に置いた音は和音
- **押さえる位置を自動で最適化** — 手の届く範囲・ポジション移動・弦移動などのコストが最小になる運指を動的計画法で探索。左手はなるべく同じポジションに留め、動くのは休符や開放弦の間を優先。12フレットより上は押さえにくいので避け（カポの有無に関係なく実際の位置で判断）、タッピングはほかに弾き方がないときだけ使う。和音は弦が重ならないように割り当て、人の手で押さえられる形だけを使う（1フレット1本の指で、押さえる音はすべて手の範囲に収める＝はみ出すストレッチはしない・人差し指以外で離れた弦を押さえない・セーハの間で開放弦を鳴らさない・低い弦ほど遠いフレットになる逆向きの形は避ける）
- **手の大きさ** — 普通（4フレット：人差し指〜小指）／小さめ（3フレット：小指を使わない）。小さめにすると手の移動は増えるが、届かない形は出ない
- **左手の区間表示** — 指板には、今の押さえ方のまま押さえておける前後の音（同じ弦で別のフレットにならない範囲。アルペジオなら和音の形）を薄く、今鳴らしている音だけ濃く表示。「このまま あと○音」と、次に移動するときは移動先の枠と「次: ○f〜へ移動」を表示。TAB譜の下にもポジションが変わる位置を表示
- **奏法も判定** — ピッキング（ダウン/アップ）/ ハンマリング / プリング / スライド / タッピング / 和音。押さえる指（1〜4）も表示
- **カポも最適化** — カポ位置ごとに計算して一番弾きやすい位置を選択（固定も可）。この機能だけの設定で、他のタブとは連動しない
- **出せない音は近似** — 音域外はオクターブをずらした近似音（≈）、押さえきれない和音の音は省略して明示。和音では、同じ音名の音がほかにある音から省略し（響きは変わらない）、近似でほかの音と同じ音になる押さえ方は使わない
- **再生とスクロール** — ▶で指板上の押さえ位置が流れて音も鳴る。シークバー・前後ボタン・TAB欄のクリックで好きな位置を確認
- **Phrase Swipe から読み込み** — [Phrase Swipe](https://github.com/yurippeeee/phrase-swipe) の「ギター用に書き出し」で作ったJSONを「📥 Phrase Swipe から」（または共有のインポート）で選び、メロディ / 伴奏（和音＋ベース）/ 伴奏（ベースなし）/ ベースだけ のどれかを読み込みます。実音・16分単位のまま入り、キー（マイナーは平行調のメジャー）・BPM・小節数も合わせます（最大16小節）

### 保存・共有

- **自動保存** — 編集内容は常にlocalStorageへ保存
- **名前を付けて保存** — 進行・メロディー・バッキング・BPM・パターンをまとめて複数保持
- **インポート / エクスポート** — JSONファイルで書き出し・読み込み。ドラッグ&ドロップ対応。人と交換できます

## 使い方

サーバー不要で `index.html` を直接ブラウザで開けば動きます。ローカルサーバーで動かす場合:

```bash
python -m http.server 8423
```

その後 `http://localhost:8423` を開いてください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構成 |
| `chords.js` | コードデータベース、スケール定義、コード解析エンジン |
| `tab-engine.js` | フレーズ→TAB の自動運指エンジン（DOM非依存） |
| `phrase.js` | フレーズ→TAB タブのUI・再生 |
| `app.js` | UI描画、音声合成、エフェクト、ピアノロール、永続化 |
| `style.css` | スタイル |

コードの押さえ方を増やしたいときは `chords.js` の `OPEN_SHAPES`（オープンコード）と `MOVABLE_SHAPES`（バレーフォーム）に1行追加するだけです。

## 交換されるデータについて

エクスポートされるJSONに含まれるのは、押さえ方（弦とフレットの数値）とディグリーの並び、拍数などの抽象データのみです。曲名・歌詞・メロディー譜としての楽曲データは含まれない設計になっています。
